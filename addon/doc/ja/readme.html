BOA: Better Office Accessibility

BOAは、Microsoft Office用の強力なアクセシビリティ向上ツールスイートであり、NVDAユーザーのスクリーンリーダー体験を大幅に改善するように設計されています。アクセスできないUIコンポーネントを直接修正し、ExcelおよびPowerPoint用の高速ナビゲーションツールを導入します。

🚀 機能

Excelの機能向上

1. シートレイアウト分析とキャッシュ

Excelワークシートを即座にスキャンして、その構造、非表示の要素、およびデータブロックを把握します。 * 仕組み: BOAはシートを迅速にスキャンし、アクティブなデータブロックを読み上げます。また、非表示のワークシートタブ、アクティブなフィルター、保護ビュー、および非表示の外側の境界（例：シートの右端付近の列が非表示になっている場合など。これにより、画面外のデータを見落とすことを防ぎます）についても警告します。 * データナビゲーション: スキャン後、データブロックジャンプのホットキーを使用して、検出されたデータブロック間でカーソルを即座に移動させることができ、数千もの空のセルを簡単にバイパスできます。

2. 一括シートオーガナイザー

完全にアクセシブルなダイアログを使用して、複数のシートを一度に並べ替えおよび整理します。 * 仕組み: シートを選択し、新しい位置に割り当てることができるダイアログを開きます。移動が予定されているシートはデータテーブルに一覧表示されます（誤って追加した場合は Del キーで削除可能）。OK をクリックすると、ワークブックが即座に再配置されます。

3. クイックシートムーバー

キーボードショートカットを使用して、アクティブなシートを左、右、最初、または最後に即座に移動します。

4. アクセシブルなシート名の変更

  • シート名を変更する際、NVDAの標準の機能では入力している文字の読み上げが困難な場合があります。
  • BOAは SafeRichEdit エンジンを使用するカスタムの ExcelSheetRenameEdit クラスを挿入します。これにより、名前の変更中に文字、単語、または行単位で正確に読み上げることができます。これは、既存のデフォルトのシート名変更動作に対する機能強化として機能します。

5. 非表示の行/列トラッカー

  • グリッド上の移動を事前に追跡し、非表示またはフィルター処理されたデータを見落とすことを防ぎます。
  • 分断されたセルの通過: グリッドの高度に分断された、または非表示のセクションを飛び越えた場合（例えば、行4〜9が非表示になっているため行3から行10に移動した場合）、BOAは「行4から9が非表示」と明示的にアナウンスします。これにより、構造内でデータがスキップされたことを常に把握できます。

6. 条件付き書式アナウンサー

  • Excelの条件付き書式ルールによって動的に変更されたセルの色、フォントスタイル、および背景の陰影を自動的に読み上げます。
  • セルの生の基礎値だけでなく、実際の視覚的状態を提供します。最初は、セルにフォーカスしたときに「条件付き書式あり、およびその他の軽微な詳細」と読み上げられます。包括的な情報が必要な場合は、詳細ホットキー構成である NVDA+E に続いて F を使用します。

7. 選択範囲の読み上げの改善

セルまたは範囲が選択されたか、または選択解除されたかを読み上げます。

8. セルモニター:

  • セルモニター: コマンドパスを使用して、特定のセルをメモリスロットに割り当てます。割り当てられた数字のスロットを使用して、いつでも戻って値を読み上げることができます。
  • 継続的な監視: スロットに登録されたセルはバックグラウンドで自動的に監視されます。Excelが再計算またはセルの編集を実行すると、BOAは即座に新しい値を読み上げます。手動で切り替えるか、コマンドスロットを介してすべてクリアできます。
  • Excel: セルモニターProアップグレード:
  • スロットマネージャーダイアログ (NVDA+E, then Alt+M): アクティブに監視しているすべてのセルを一覧表示するダイアログを開きます。Enter を押すと即座にそのセルにジャンプします。
  • ワープバック (NVDA+E, then \): スロットを確認した後、直前に作業していたセルに瞬時にテレポートして戻ります。
  • 直接スロットジャンプ (Prefix + Alt + Slot Number): プレフィックスを完全にバイパスして、割り当てられたセルスロットに即座にジャンプします。

9. パワーエディター

  • Excel: パワーエディター（アクセシブルな数式エディター）: 巨大な数式を変更するための革新的な機能です。
  • NVDA+E の後に F2 を1回押す: アクティブなセルの未加工の数式文字列を即座に読み上げます（数式がない場合は「数式なし」と読み上げます）。
  • NVDA+E の後に F2 を2回連続で押す: 巨大な入れ子（ネスト）構造の数式を安全に変更できる、完全にアクセシブルな複数行エディターを開きます。通常の Enter キーで改行を挿入して読みやすくし、Ctrl+Enter でExcelに保存します。
  • 安全性のチェック: 数式がシートを破損する前に構文エラーを安全に検出し、計算後のエラー（#NAME? や #DIV/0! など）を検出して、数式が破損している場合に即座に警告します。

10. 数式監査および評価の強化

  • Excel: 数式監査および評価: 参照元および参照先を確実に追跡するためのカスタムショートカット（NVDA+E の後に Shift+P、および NVDA+E の後に Shift+D）を追加しました。さらに、Excel標準の「数式の評価」ダイアログが完全にアクセシブルになりました。計算をステップ実行するたびに、NVDAが評価結果を自動的に読み上げます！

PowerPointの機能向上

1. アクセシブルなカラーピッカー

  • PowerPointの「色の設定」ダイアログをアンロックします。
  • 「赤」、「緑」、「青」の入力ボックスを正しく識別して明示的に読み上げます（PowerPointRGBEdit をオーバーライドすることによって実現）。
  • これまで見えなかったHex（16進数）入力フィールドをマッピングし、NVDAが完全なHexカラー値をすっきりと読み上げられるようにします。

2. 標準の色グリッドのサポート

  • PowerPointの「標準」の色の六角形グリッドを移動すると、通常は「グラフィック」と読み上げられるか、無音になります。
  • BOAは六角形グリッド上の矢印キーによる移動を追跡し、非表示のカラー値をバックグラウンドで取得して、リアルタイムでアナウンスします（例：「カラー #FF0000」）。

3. 一括スライドオーガナイザー:

  • PowerPoint: 一括スライドオーガナイザー (実験的機能) (NVDA+E, then X): Excelの機能と同様に、完全にアクセシブルなダイアログを使用して、複数のPowerPointスライドを一度に再配置、移動、整理できるようになりました。

4. スライドレイアウトアナウンサー

  • PowerPoint: スライドレイアウトアナウンサー (実験的機能) (NVDA+E, then L): 現在アクティブなスライドを即座にスキャンして、その空間的レイアウトとアクセシビリティの制限を把握し、完全にスムーズで応答性の高いスクリーンリーダー体験を保証します。つまり、Excelのシートレイアウト分析と同様に、現在のスライドに関する詳細情報を取得できます。

5. 完全なドキュメント [PPT] 分析

  • PowerPoint: 完全なドキュメント分析 (実験的機能) (NVDA+E, then D): NVDAの音声エンジンをフリーズさせることなく、プレゼンテーション全体をマッピングする、高度なバックグラウンド処理アクセシビリティツールです。詳細なナビゲーションが可能な「仮想目次」を提供し、閲覧順序の不整合（表示順序とZ順序の不一致）を検出し、「テキストの壁」スライドにフラグを立て、SmartArtやデータテーブルなどの複雑なオブジェクトをマッピングします。

6. シェイプ移動 [調整] の機能向上:

  • PowerPoint: 図形移動のオーディオモード (実験的機能): PowerPointキャンバスに3D立体音響の手がかりを導入します。オブジェクトを移動するときにその方向と境界制限を示す音響フィードバックを提供し、空間認識を大幅に向上させます。

Wordの機能向上:

1. Paul氏のWord Accessアドオンから着想・派生したドキュメント分析:

  • Word: ドキュメント分析 (NVDA+E, then D): Wordドキュメントの構造概要を即座に表示します。(Paul氏への感謝と敬意の特別なメモ: この機能は、彼の素晴らしい「Word Access」アドオンから直接インスピレーションを得たものです。この分野における彼の先駆的な取り組みに深く感謝いたします！)

2. 書式監査

  • Word: 書式監査 (NVDA+E, then F): Wordドキュメントの書式の不整合をスキャンし、視覚的な標準を満たしているか確認します。

3. 脚注リーダー:

  • Word: 自動脚注アナウンサー: カスタムのBOA設定に基づき、読書中に行内で脚注が自動的に読み上げられるようになります。(注意: 文末脚注およびコメントのサポートは将来のリリースで予定されています)。

インフラストラクチャおよび技術的メカニズム

コマンドプレフィックスモード

他のNVDAプラグインとのキー割り当ての衝突を防ぐため、BOAはコマンドプレフィックスモードを使用します： 1. 起動ホットキーを押してコマンドモードに入ります。高音のビープ音が聞こえます。デフォルトは NVDA+E です。 2. セカンダリキーを押して特定の機能をトリガーします。 3. 無効なキーを押すと、エラーのビープ音が鳴ります。

カスタマイズと設定パネル

  • BOAの機能は完全にモジュール化されており、いつでも有効または無効にできます。NVDAメニュー -> 設定 -> 設定 -> BOA Office Enhancements に移動して、個々の機能をオンまたはオフに切り替えます。
  • インテリジェントアクセラレータキー: パネル内のすべての設定には、数学的に一意の Alt+Key アクセラレータショートカットが割り当てられています。たとえば、Alt+E を押すと即座にExcelグループにジャンプし、Alt+P はPowerPoint、Alt+W はWordにジャンプします。
  • 設定は独立したJSONファイル（boa_settings.json）に安全に保存されるため、NVDAのコア構成が破損することはありません。
  • 将来的にMicrosoft Officeが公式にアクセシビリティのバグを修正した場合、アドオンの他の機能を損なうことなく、BOAの特定のオーバーライドフックのみを安全に無効にすることができます。
  • 入力ジェスチャーのカスタマイズ: すべてのOfficeアプリのすべての機能がNVDA標準の「入力ジェスチャー」ダイアログに明示的に公開されており、すべてのキーボードショートカットを完全に自由にカスタマイズできます。

セキュリティと統合境界

  • クリップボードの挿入では、ウィンドウのフォアグラウンドプロセスIDを厳密に検証し、他のアプリケーションへのデータ漏洩を防ぎます。
  • 一部のカスタムホットキーは、NVDAの「入力ジェスチャー」ダイアログの「Better Office Accessibility」カテゴリの下に完全に公開されています。

📋 必要条件

  • NVDA: バージョン 2026.1.0 以降。
  • アプリケーション: Microsoft Excel および Microsoft PowerPoint。

💾 インストール

  1. 最新の .nvda-addon リリースファイルをダウンロードするか、NVDAの標準の「アドオンストア」内で見つけます。
  2. ファイルからインストールする場合は、ファイルを開くか、NVDAのメニュー -> ツール -> アドオンストア -> 外部ファイルからインストール を使用します。
  3. NVDAを再起動します。

新機能

データ末尾レーダー

大きなスプレッドシートを移動しているとき、空のセルがリストの末尾を意味しているのか、それとも単にデータにギャップがあるだけなのかを判断するのは難しい場合があります。データ末尾レーダーは、空のスペースを盲目的に矢印キーで移動するのを防ぐためのスマートな周囲確認として機能します。 空のセルに移動するたびに、BOAは移動方向の残りのセルを即座にスキャンします。データが全く残っていない場合は、事前に以下のようにアナウンスします： * "これより下にはデータはありません" * "これより上にはデータはありません" * "これより右にはデータはありません" * "これより左にはデータはありません" 設定オプション: この機能は、NVDAのメニュー -> 設定 -> 設定 -> BOA Office Enhancements から設定できます。スプレッドシートには非表示の複雑さ（非表示の数式や折りたたまれた行など）が含まれている場合があるため、レーダーは3つの動作モードを提供します： 1. オフ: レーダーを完全に無効にします。 2. 厳密なメモリチェック (CountA) [デフォルト]: 最も安全で高速なアプローチです。スプレッドシートの生メモリをチェックします。足元に何か（非表示の行、テキスト、数値、または非表示の数式を含む）を検出した場合、誤報を防ぐために完全に無音のままになります。シートの残りの部分が数学的に100%空白である場合にのみ「データはありません」と読み上げます。 3. 表示データのみ (Math Engine): 複雑なシート向けに設計された高度なエンジンです。非表示の行や非表示の数式（例：=""）をインテリジェントに除外します。進行方向に実際の表示可能な数値またはテキストが残っている場合にのみ、無音になります。
