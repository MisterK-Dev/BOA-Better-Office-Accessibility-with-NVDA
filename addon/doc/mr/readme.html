BOA: Better Office Accessibility

BOA ही Microsoft Office साठी ॲक्सेसिबिलिटी एन्हान्समेंट्सची एक शक्तिशाली प्रणाली आहे, जी NVDA वापरकर्त्यांसाठी स्क्रीन रीडरचा अनुभव मोठ्या प्रमाणावर सुधारण्यासाठी तयार केलेली आहे. ती इनॲक्सेसिबल UI घटकांना थेट पॅच करते आणि Excel आणि PowerPoint साठी जलद नेव्हिगेशन साधने सादर करते.

🚀 फीचर्स

Excel एन्हान्समेंट्स

1. Sheet Layout Analyzer आणि Caching

कोणत्याही Excel Worksheet ची रचना, लपवलेले घटक आणि Data Blocks समजून घेण्यासाठी ते त्वरित स्कॅन करा. * हे कसे काम करते: BOA शीट त्वरीत स्कॅन करते आणि सक्रिय Data Blocks घोषित करते. हे तुम्हाला Hidden Worksheet Tabs, सक्रिय Filters, Protected Modes, आणि Hidden Outer Boundaries (उदा., जर शीटच्या उजव्या काठाजवळील Columns लपवलेले असतील, जेणेकरून तुमचा स्क्रीनबाहेरील डेटा चुकू नये) यांबद्दल देखील चेतावणी देते. * डेटा नेव्हिगेशन: स्कॅनिंगनंतर, तुम्ही हजारो रिकाम्या Cells ला सहजरीत्या पार करून, शोधलेल्या Data Blocks मध्ये तुमचा कर्सर झटपट वळवण्यासाठी डेटा ब्लॉक जंप हॉटकीज वापरू शकता.

2. Bulk Sheet Organizer

पूर्णपणे ॲक्सेसिबल डायलॉग वापरून एकाच वेळी अनेक Sheets त्वरित रीऑर्डर करा आणि व्यवस्थापित करा. * हे कसे काम करते: एक डायलॉग उघडतो जिथे तुम्ही Sheet निवडू शकता आणि नवीन स्थानावर मॅप करू शकता. शेड्युल केलेल्या मूव्ह्ज डेटा टेबलमध्ये सूचीबद्ध केल्या जातात (चूक काढण्यासाठी Del दाबा). OK क्लिक करा आणि तुमचे Workbook त्वरित पुनर्रचना केले जाईल.

3. Quick Sheet Mover

तुमचे कीबोर्ड शॉर्टकट वापरून सक्रिय Sheet डावीकडे, उजवीकडे, अगदी सुरुवातीला किंवा अगदी शेवटी त्वरित हलवा.

4. ॲक्सेसिबल Sheet Renaming

  • Sheet चे नाव बदलताना, तुम्ही टाईप करत असलेले कॅरेक्टर्स वाचण्यात NVDA ला नेटिव्हरीत्या अडचण येते.
  • BOA एक कस्टम ExcelSheetRenameEdit क्लास इंजेक्ट करते जो SafeRichEdit इंजिन वापरतो, याचा अर्थ नाव बदलताना तुम्ही कॅरेक्टर, शब्द किंवा ओळीनुसार अचूक वाचू शकता. हे विद्यमान डीफॉल्ट रिनेमिंग वर्तनाला एन्हान्समेंट म्हणून काम करते.

5. Hidden Row/Column Tracker

  • तुमचा लपवलेला किंवा फिल्टर केलेला डेटा चुकू नये म्हणून ग्रिडवरील तुमच्या हालचालीचा अगोदरच मागोवा घेतो.
  • क्रॉस्ड फ्रॅगमेंटेड Cells: जर तुम्ही ग्रिडच्या मोठ्या प्रमाणावर विखुरलेल्या किंवा लपलेल्या भागावरून उडी मारली (उदा., Row 3 वरून Row 10 वर जाणे कारण Rows 4–9 लपलेल्या आहेत), तर BOA स्पष्टपणे घोषित करते "Rows 4 through 9 hidden". यामुळे तुम्हाला नेहमी माहित असते की रचनेमधील डेटा कधी वगळला गेला आहे.

6. Conditional Formatting Announcer

  • Excel च्या Conditional Formatting नियमांमुळे डायनॅमिकरीत्या बदललेल्या Cells चा रंग, फॉन्ट स्टाईल आणि बॅकग्राउंड शेड आपोआप वाचते.
  • तुम्हाला फक्त मूळ व्हॅल्यू देण्याऐवजी Cell ची खरी व्हिज्युअल स्थिती देते. सुरुवातीला, Cell वर फोकस केल्यावर, ते घोषित करते "has conditional formatting, and some other minor details". सर्वसमावेशक माहितीसाठी, तपशीलवार हॉटकी कॉन्फिगरेशन वापरा जे NVDA E आणि F आहे.

7. उत्तम Selection घोषणा

Cell किंवा रेंज निवडली असल्यास किंवा निवड काढली असल्यास ते वाचते.

8 Cell monitor:

  • Cell Monitor: ठराविक Cells ना मेमरी स्लॉटमध्ये मॅप करण्यासाठी कमांड पाथ्स वापरा. तुम्ही असाइन केलेला संख्यात्मक स्लॉट वापरून कधीही परत जाऊन ते वाचू शकता.
  • Continuous Monitoring: स्लॉट केलेले Cells आपोआप बॅकग्राउंडमध्ये मॉनिटर केले जातात. जर Excel ने recalculation किंवा Cell edit केले, तर BOA लगेच नवीन व्हॅल्यू घोषित करते. मॅन्युअली टॉगल करा किंवा कमांड स्लॉट्सद्वारे सर्व क्लिअर करा.

PowerPoint एन्हान्समेंट्स

1. Accessible Color Pickers

  • PowerPoint मधील Custom Color डायलॉग अनलॉक करते.
  • "Red", "Green", आणि "Blue" एडिट बॉक्सेस ओळखते आणि स्पष्टपणे अचूक वाचते (PowerPointRGBEdit ला ओव्हरराइड करून).
  • आधी अदृश्य असलेले Hex इनपुट फील्ड मॅप करते जेणेकरून NVDA पूर्ण Hex कलर व्हॅल्यू स्पष्टपणे वाचू शकेल.

2. Standard Color Grid Support

  • PowerPoint "Standard" कलर हेक्सागॉन ग्रिड नेव्हिगेट करताना सहसा "Graphic" असे वाचते किंवा शांत राहते.
  • हेक्सागॉन ओलांडणाऱ्या तुमच्या ॲरो कीजचा BOA मागोवा घेते आणि लपलेली कलर व्हॅल्यू शांतपणे मिळवते, ती तुम्हाला रिअल-टाइममध्ये घोषित करते (उदा., "Color #FF0000").

इन्फ्रास्ट्रक्चर आणि टेक्निकल मेकॅनिझम्स (Infrastructure & Technical Mechanisms)

Command Prefix Mode

इतर NVDA प्लगइन्ससोबत कीस्ट्रोक संघर्ष टाळण्यासाठी, BOA एक Command Prefix Mode वापरते: 1. कमांड मोड एंटर करण्यासाठी ॲक्टिव्हेशन हॉटकी दाबा. तुम्हाला एक उच्च आवाजाचा बीप ऐकू येईल. 2. विशिष्ट फीचर ट्रिगर करण्यासाठी दुसरी की दाबा. 3. जर तुम्ही चुकीची की दाबली, तर तुम्हाला एक एरर बीप ऐकू येईल.

Customization आणि Settings पॅनेल

  • BOA फीचर्स पूर्णपणे मॉड्युलर आहेत आणि कधीही सक्षम किंवा अक्षम केले जाऊ शकतात. वैयक्तिक फीचर्स चालू किंवा बंद करण्यासाठी NVDA Menu -> Preferences -> Settings -> BOA Office Enhancements वर जा.
  • Intelligent Accelerator Keys: पॅनेलमध्ये प्रत्येक सेटिंगमध्ये गणितीयदृष्ट्या अद्वितीय असा Alt+Key ॲक्सलरेटर शॉर्टकट आहे. उदाहरणार्थ, Excel ग्रुपवर झटपट जाण्यासाठी Alt+E दाबा, PowerPoint साठी Alt+P, आणि Word साठी Alt+W दाबा.
  • सेटिंग्स एका स्टँडअलोन JSON फाईल (boa_settings.json) मध्ये सुरक्षितपणे सेव्ह केल्या जातात, ज्यामुळे तुमचे मुख्य NVDA कॉन्फिगरेशन कधीही खराब होणार नाही याची खात्री होते.
  • जर Microsoft Office ने भविष्यात एखादा ॲक्सेसिबिलिटी बग अधिकृतपणे दुरुस्त केला, तर तुम्ही ॲड-ऑनची उर्वरित कार्यक्षमता न गमावता BOA चा विशिष्ट ओव्हरराइड हूक सुरक्षितपणे अक्षम करू शकता.

सुरक्षा आणि इंटिग्रेशन सीमा (Security & Integration Boundaries)

  • क्लिपबोर्ड इंजेक्शन्स अन्य ॲप्लिकेशन्समध्ये डेटा लीक होण्यापासून रोखण्यासाठी विंडो फोरग्राउंड प्रोसेस आयडीची काटेकोरपणे पडताळणी करतात.
  • काही कस्टम हॉटकीज NVDA च्या Input Gestures डायलॉगमध्ये "Better Office Accessibility" कॅटेगरी अंतर्गत पूर्णपणे उघड केलेल्या आहेत.

📋 आवश्यकता (Requirements)

  • NVDA: आवृत्ती 2026.1.0 किंवा त्यापुढील.
  • ॲप्लिकेशन्स (Applications): Microsoft Excel आणि Microsoft PowerPoint.

💾 इन्स्टॉलेशन (Installation)

  1. नवीनतम .nvda-addon रिलीज फाईल डाउनलोड करा, किंवा नेटिव्ह NVDA ॲड-ऑन स्टोअरमध्ये ती शोधा.
  2. फाईलमधून इन्स्टॉल करत असल्यास, फाईल उघडा किंवा NVDA's Add-on Store -> Install from external file वापरा.
  3. NVDA रीस्टार्ट करा.
