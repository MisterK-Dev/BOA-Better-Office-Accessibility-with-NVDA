BOA：更佳的 Office 无障碍体验

BOA 是一套功能强大的 Microsoft Office 无障碍增强套件，旨在极大地改善 NVDA 用户的屏幕阅读器使用体验。它直接修复了不可访问的 UI 组件，并为 Excel 和 PowerPoint 引入了快速导航工具。

🚀 功能特性

Excel 增强功能

1. Sheet Layout Analyzer & Caching

立即扫描任何 Excel 工作表，以了解其结构、隐藏元素和数据块。 * 工作原理： BOA 快速扫描工作表并播报活动的数据块。它还会向您发出有关隐藏工作表标签页、活动筛选器、保护模式以及隐藏的外部边界的警告（例如，如果工作表右边缘附近的列被隐藏，以防止您遗漏屏幕外的数据）。 * 数据导航： 扫描完成后，您可以使用数据块跳转热键在发现的数据块之间立即传送光标，轻松绕过数千个空白单元格。

2. Bulk Sheet Organizer

使用完全无障碍的对话框一次性立即重新排序和排列多个工作表。 * 工作原理： 打开一个对话框，您可以在其中选择工作表并将其映射 to 新位置。计划的移动将列在数据表中（按 Del 可删除错误）。点击 OK，您的工作簿将立即重新排列。

3. Quick Sheet Mover

使用键盘快捷键立即将当前工作表向左、向右移动，或移动到最开头或最末尾。

4. Accessible Sheet Renaming

  • 重命名工作表时，NVDA 原生难以朗读您输入的字符。
  • BOA 注入了使用 SafeRichEdit 引擎的自定义 ExcelSheetRenameEdit 类，这意味着您可以在重命名时精确地按字符、单词或行进行阅读。这可以作为对现有默认重命名行为的增强。

5. Hidden Row/Column Tracker

  • 主动跟踪您在网格中的移动，以防止您遗漏隐藏或被筛选的数据。
  • 跨越分段单元格： 如果您跨越网格中严重碎片化或隐藏的部分（例如，由于第 4-9 行被隐藏，从第 3 行移到第 10 行），BOA 会明确播报“隐藏了从 4 到 9 的行”。这可确保您始终了解结构中何时跳过了数据。

6. Conditional Formatting Announcer

  • 自动读取因 Excel 条件格式规则而动态改变的单元格颜色、字体样式和背景底纹。
  • 为您提供单元格的真实视觉状态，而不仅仅是原始的基础值。最初，当聚焦于单元格时，它会播报“has conditional formatting, and some other minor details”（具有条件格式以及其他一些次要细节）。要获取完整信息，请使用详细的热键配置，即 NVDA E 和 F。

7. Better selection announcement

在单元格或范围被选中或取消选中时进行朗读。

8 Cell Monitor

  • Cell Monitor： 使用命令路径将特定单元格映射到内存槽。您可以随时使用分配的数字槽跳转回来并读取它们。
  • 持续监视： 处于槽中的单元格将在后台自动受到监视。如果 Excel 触发重新计算或单元格编辑，BOA 会立即播报新值。可通过命令槽手动切换或全部清除。
  • Excel: Cell Monitor Pro Upgrades:
  • Slot Manager Dialog（NVDA+E，然后按 Alt+M）： 打开一个对话框，列出所有处于活动监视状态的单元格。按 Enter 可立即跳转到其中一个单元格。
  • Warp Back（NVDA+E，然后按 \）： 在检查槽后，立即将您传送回先前工作的单元格。
  • Direct Slot Jump（Prefix + Alt + Slot Number）： 绕过前缀并立即跳转到已分配的单元格槽。

9 Power Editor

  • Excel: The Power Editor（无障碍公式编辑器）： 修改海量公式的绝对游戏规则改变者。
  • 单击 NVDA+E，然后按 F2： 立即播报当前单元格的原始公式字符串（或者播报“No formula”/无公式）。
  • 双击 NVDA+E，然后按 F2： 打开一个完全无障碍的多行编辑器，以安全地修改庞大的嵌套公式。使用原生的 Enter 可以添加换行以便于阅读，而按 Ctrl+Enter 则将其保存回 Excel。
  • 安全检查： 在语法错误损坏您的工作表之前安全地捕获它们，并检测计算后错误（例如 #NAME? 或 #DIV/0!），以便在公式损坏时立即向您发出警告。

10 公式审核与评估增强功能：

  • Excel: Formula Auditing & Evaluation： 添加了自定义快捷键（NVDA+E，然后按 Shift+P 以及 NVDA+E，然后按 Shift+D）以可靠地追踪引用单元格（Precedents）和从属单元格（Dependents）。此外，Excel 原生的“评估公式”对话框现已完全无障碍；当您逐步执行计算时，NVDA 会自动读取评估结果！

PowerPoint 增强功能

1. Accessible Color Pickers

  • 解锁 PowerPoint 中的“自定义颜色”对话框。
  • 正确识别并明确朗读“红”、“绿”、“蓝”编辑框（通过重写 PowerPointRGBEdit）。
  • 映射了先前不可见的十六进制（Hex）输入字段，以便 NVDA 可以清晰地读取完整的十六进制颜色值。

2. Standard Color Grid Support

  • 在 PowerPoint 的“标准”彩色六边形网格中导航时，通常只会朗读为“图形”或保持静音。
  • BOA 会在六边形网格中跟踪您的方向键，并静默获取隐藏的颜色值，实时向您播报（例如，“Color #FF0000”）。

3 Bulk Slide Organizer

  • PowerPoint: Bulk Slide Organizer (Experimental)（NVDA+E，然后按 X）： 类似于 Excel 功能，您现在可以使用完全无障碍的对话框一次性立即重新排序、移动和排列多张 PowerPoint 幻灯片。

4 Slide Layout Analyzer

  • PowerPoint: Slide Layout Analyzer (Experimental)（NVDA+E，然后按 L）： 立即扫描您当前活动的幻灯片，以了解其空间布局 and 无障碍限制，确保完全流畅且响应迅速的屏幕阅读器体验。这意味着，您将在这里获得类似于 Excel 工作表布局分析器的当前幻灯片详细信息。

5 PowerPoint Document Analyzer

  • PowerPoint: Complete Document Analyzer (Experimental)（NVDA+E，然后按 D）： 一款高度先进的、在后台处理的无障碍工具，可以绘制出整个演示文稿的结构，而不会冻结 NVDA 的语音引擎。它提供了一个可深度导航的虚拟目录，检测阅读顺序不匹配问题（视觉顺序 vs. Z 轴顺序），标记“大段文字”（Wall of Text）幻灯片，并映射 SmartArt 和数据表等复杂对象。

6 shape movement [adjustment] enhancements:

  • PowerPoint: Shape Movement Audio Mode (Experimental)： 为 PowerPoint 画布引入 3D 空间音频提示。在您移动对象时提供听觉反馈，指示对象的移动方向和边界限制，从而极大地提高空间感知能力。

Word 增强功能：

1. Document Analyzer（灵感来源于 Paul 的 Word Access 插件）：

  • Word: Document Analyzer（NVDA+E，然后按 D）： 立即调出 Word 文档的结构概述。（特别致谢 Paul：此功能的灵感直接源自他出色的“Word Access”插件。我们对他在此领域的奠基性工作表示深切的感谢！）

2 Formatting Auditor

  • Word: Formatting Auditor（NVDA+E，然后按 F）： 扫描您的 Word 文档以查找格式不一致，确保符合视觉标准。

3 脚注阅读器：

  • Word: Automated Footnote Announcer： 根据您的自定义 BOA 设置，现在在您阅读时会自动在行内播报脚注。（注意：对尾注和批注的支持计划在未来的版本中推出）。

基础设施与技术机制

命令前缀模式

为了防止与其他 NVDA 插件发生按键冲突，BOA 使用了命令前缀模式： 1. 按下激活热键以进入命令模式。您将听到一声高音提示音。默认是 NVDA 加上 E。 2. 按下辅助键以触发特定功能。 3. 如果您按下了无效的键，您将听到一声错误提示音。

自定义与设置面板

  • BOA 功能是完全模块化的，可以随时启用或禁用。转到 NVDA Menu -> Preferences -> Settings -> BOA Office Enhancements（NVDA 菜单 -> 首选项 -> 设置 -> BOA Office 增强功能）来开启或关闭各个功能。
  • 智能加速键： 面板内的每一个设置都具有数学上唯一的 Alt+Key 加速键快捷键。例如，按 Alt+E 可立即跳转到 Excel 组，按 Alt+P 跳转到 PowerPoint，按 Alt+W 跳转到 Word。
  • 设置安全地保存到独立的 JSON 文件（boa_settings.json）中，确保您的 NVDA 核心配置永远不会损坏。
  • 如果 Microsoft Office 在未来正式修复了某个无障碍 Bug，您可以安全地禁用 BOA 的特定重写钩子，而不会失去该插件的其他功能。
  • 输入手势自定义： 所有 Office 应用中的所有功能都已明确公开在原生 NVDA 的“输入手势”对话框中，赋予您完全自由来自定义每个键盘快捷键。

安全与集成边界

  • 剪贴板注入严格验证窗口前台进程 ID，以防止数据泄露到其他应用程序中。
  • 某些自定义热键完全公开在 NVDA“输入手势”对话框的“Better Office Accessibility”类别下。

📋 系统要求

  • NVDA： 2026.1.0 或更高版本。
  • 应用程序： Microsoft Excel 和 Microsoft PowerPoint。

💾 安装方法

  1. 下载最新的 .nvda-addon 发布文件，或在原生的 NVDA 插件商店中找到它。
  2. 如果从文件安装，请打开该文件或使用 NVDA's Add-on Store -> Install from external file。
  3. 重启 NVDA。

在大型电子表格中导航时，很难判断一个空白单元格是意味着您已到达列表的末尾，还是仅仅数据中存在间隙。End of Data Radar 作为一种智能周边检查，可避免您盲目地在空白区域中按方向键。 每当您导航到空白单元格时，BOA 会立即在您的移动方向上扫描其余单元格。如果绝对没有剩余数据，它将主动播报： * “下方没有更多数据” * “上方没有更多数据” * “右侧没有更多数据” * “左侧没有更多数据” 配置选项： 您可以通过 NVDA Preferences -> Settings -> BOA Office Enhancements 配置此功能。由于电子表格可能包含隐藏的复杂情况（如不可见的公式或折叠的行），雷达提供了三种工作模式： 1. Off：完全禁用雷达。 2. Strict Memory Check (CountA) [默认]：最安全、最快速的方法。它检查电子表格的原始内存。如果它检测到您下方有任何内容（包括隐藏行、文本、数字或不可见公式），它会保持完全静音以防止误报。只有当工作表的其余部分在数学上 100% 为空白时，它才会播报“No more data”。 3. Visible Data Only (Math Engine)：专为复杂工作表设计的高度先进的引擎。它智能地过滤掉隐藏行和不可见的公式（例如 =""）。只有在您的路径上确实剩下实际可见 of 数字或文本时，它才会保持静音。

版本 1.3.0 — 2026-06-05

新功能

Bug 修复

  • 绝对边缘边界检测： 使用绝对一维数学边界检查（Row 1048576 和 Column 16384）取代了原生 COM 的 UsedRange 边缘检查，以确保即使隐藏的行/列位于活动数据块之外很远，也能检测到它们。
  • 延迟加载 COM 属性 safe bailouts： 加固了 COM 属性循环，以防止在评估数百万个连续的隐藏结构时 NVDA 线程发生冻结。

版本 1.2.0 — 2026-06-03

最终发布版本。

新功能

  • App-Launch Caching： 重大架构重构。核心模块现在仅在您聚焦于 Office 应用程序时才会延迟加载，从而消除了启动延迟，彻底解决了重命名对话框中“未知”对象焦点故障，并保留了多文件代码库结构。
  • Enhanced Cell Tracker (1D COM Math)： 重写了隐藏单元格间隙检测逻辑，仅评估一维截面（current_col 或 current_row）。这使 COM 计算负荷减少了 1600 多万个单元格，瞬间消成了在跳转隐藏范围时的导航冻结。
  • Process Memory Wiping： 实现了 Excel 窗口句柄（Hwnd）跟踪，以检测用户何时关闭并重新打开 Excel。这会主动清除陈旧的全局状态内存，并彻底解决在打开新的“Book1”时错误的“Sheet hidden”播报。

Bug 修复

  • 双重选择播报： 摒弃了不可靠的异步 winUser.getKeyState，转而使用 api.getLastInputGesture()，以完美消除使用 Shift+方向键时的重复播报问题。
  • 边界检测器停用： 主动式边界检测器已停用，以保护 NVDA 原生导航的稳定性，完全回退到跨越空隙跟踪器。
